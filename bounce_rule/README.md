| 데드캣 | 강도 < 0.3σ — 저점 10일 재이탈 80%. JSON 에만 기록 (메일 없음) |
| 유니버스 | LLV 패널(core+extend) 중 ETF 제외 |

## 근거 (korean_mkt_study/crash_study.py 4~5단계, 2026-10-30~11-02 — 유니버스 2016~2026 드라이브 162,077건)
- 저점 10일 유지는 드라이브 모양(길이·낙폭 추세·거래량 추세·시총)과 무관하고 **멈춘 첫날의 크기**가 결정: 0~1% → 21%, ≥8% → 72~77%.
- 강도 ≥1.65σ 만으로 저점 유지 63%, 2020·쇼크일·시장 반등일 전 구간·시총 전 구간 동일 방향.
- 낙폭 ≤−20% 와 결합: D+2 시가 진입 5일 +2.9% / 10일 +4.5% (왕복 0.3% 차감, 2020 제외 5일 +2.7%), 저점 재이탈 24%. 얕은 드라이브(−10% 미만)에선 강한 반등도 −0.3% → 깊이 조건이 필수.
- 패널 219종목 역산 11년 323건, **2020년 92·2026년 163건 — 시장 쇼크 반등에 집중되는 이벤트형**. 평시엔 월 1건꼴.
- 쿠션 주의: 강한 반등일 종가는 79% 가 10일 안에 한 번은 되밟힌다. "저점 유지" ≠ "반등일 종가 지지".
