# 발열률 (fever_model) — 시장온도 나우캐스트 + Vblk 탄력점수

**명명**: 2026-08-14 Kane. "열을 재고(온도), 열을 내는 종목을 찾는다(탄력)" 2단 구조.
룰 4개 중 4번째 — 전체 지도는 상위 `MagicFormula/CLAUDE.md`.

**성격**: 예측이 아니라 **관측(나우캐스트)**. "누가 오를까"가 아니라
"지금 누가 움직이고 있고, 그 움직임이 어떤 구조인가". 관측 지평 **20~60거래일**
(스윙 포트와 같은 주기). 장기 보유 명단이 아니다.

## 1단 — 시장온도 (나우캐스트)

Weis Wave 파동을 접어 만든 무차원 특징 13개 → 반기 패널 k=3 모델(스케일러+중심점)에
trailing 창으로 배정. **온도 = 요동(장기+단기) 종목 비율.**

| 국면 | 성격 |
|---|---|
| 단기 요동 | 요동이 갓 시작 (창 후반만 진폭 2배) |
| 장기 요동 | 창 전체가 요동 |
| 저변동 | 기본 상태 |

**채택 파라미터: W=60 / MIN_WAVES=4** (2026-08-13 Kane 결정 — "지연 단축이 기준안
일치보다 중요"). 판정 지연 50→약 30거래일. 대가: 뒤집힘률 8.4→10.9%/5일,
구기준(W100/M6) 공통 셀 일치 82.3%. W100/M6 은 **비교용으로 계속 병기** —
스프레드 **W60−W100 < 0** = "최근 1~5개월 냉각 진행" 신호 후보(관찰 중, 표본
2에피소드). ⚠ 부호는 2026-08-14 Kane 지시로 뒤집혔다 — 스터디노트 §5-6 은
W100−W60 기준(양수=냉각)이므로 문서 대조 시 주의.

⚠ **온도 절대 레벨은 캘리브레이션 의존** — 방향·상대 변화로 읽을 것.
⚠ **5일 단위 변화는 노이즈** — 20거래일 MA 로 읽고 일간 등락에 의미 부여 금지.
⚠ 중심점은 전 기간 학습(선견) — 워크포워드 검증 결과 모양·타이밍은 무왜곡,
레벨만 +7.6~9.7%p 상향. 백테스트 시 명시.

## 2단 — Vblk 탄력점수

**Vblk = (p1 + (p2n + p3n)/2 + p4) / 3** → 추세 33 : 눌림진폭 17 : 눌림거래량 17 : YZ 33
(2026-08-13 채택. 상관 구조 p2n·p3n 0.80 = 한 현상의 두 측정 → 블록 균등이 정직).

| 신호 | 내용 |
|---|---|
| p1 | 추세 우위 — 상승/하락 평균진폭 로그비 (최근 8파동) |
| p2n | 눌림 진폭 (역) — 점화부 = 창 후반 1/3 기준 |
| p3n | 눌림 거래량 (역) — 매물 부재 |
| p4 | YZ20 변동성 수준 |

- 점수표에 **p4 단독순위 병기** (합성의 부가가치 상시 대조).
- 과열·재가열은 **감점 아니라 플래그 표시만** (2026-08-12 결정 — 20일 지평에서
  과열 종목이 부진하지 않음. 단기 요동 페이드 −11.8%는 반기 지평 현상).
- 계단 구조(higher lows)는 **검증 후 제외 확정** — 추세 우위에 이미 흡수.

⚠ V1 설계 결함: p1 ≡ p2 (상관 1.00, 수학적 동일물)였음. V2 에서 점화부 기준으로
분리해 해결(p2n−p1 상관 0.65). **V2 채택 근거는 성과가 아니라 정합성** —
35회 표본으로는 어떤 변형도 서로 구분 불가(t≈0.7).

제목 · 요약지표 3 · 온도 그래프 → **핵심 종목(core) 섹터별 전체 표**
(섹터 순서 = homalone `config.SECTOR_ORDER`, Quickview 와 동일) → **확장 종목(extend)
중 전체 상위 30 진입분만** 섹터별 표. 표 컬럼 = 종목 · 순위(발열계 점수 병기) ·
국면 · **영역별 순위**(추세 · YZ · 눌림진폭 · 눌림거래량 — 가중치 큰 순) · 종가 · 등락률.
순위 색: 상위 10 진한 빨강 / 상위 30 흐린 빨강 / 하위 20% 파랑.
표 규격은 Quickview(`3_Quickview.py render_sector_table`)를 따른다 —
`table-layout:fixed` + colgroup 으로 **섹터 간 셀 폭 통일**, 연한 헤더 배경, CSS 변수 색상.
섹터 제목 줄은 `config.SECTOR_COLORS` 고유색(확장 전용 섹터는 STOCK_PALETTE 해시 배정),
전체 상위 30 진입 종목은 **행 배경**으로 강조 + 섹터 헤더에 "상위30 n" 배지.
숫자 열은 전부 순위이므로 헤더에 "순위" 부제를 단다.
⚠ 그래프는 흰 바탕 — `st.plotly_chart(..., theme=None)` **필수**. Streamlit 기본
`theme="streamlit"` 이 앱 다크 테마를 plotly 에 덮어써서 글자가 흐려진다(2026-08-14 실측).
