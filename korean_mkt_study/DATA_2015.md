## investor_flow 연장 대안 (케인 결정 대기)
1. **KIS inquire-investor** (공식 API, LLV `kis_fetcher.fetch_investor_netbuy`) — 종목당 3콜(~30거래일/콜), 2,400종목 ≈ 7,500콜.
   금액이 **백만원 절사** → 원 단위 이력과 정밀도 다름(LLV 는 이미 "1백만원 이하 차이 동일값" 관례). 외국인 = 외국인계 합, 기타법인 = −(개인+기관+외국인) 로 산출.
   ⚠ 미니 실계좌 워치와 같은 앱키 — 장중에 돌리지 말 것.
2. pykrx 종목별 `get_market_trading_value_by_date` — 종목당 1콜로 07-01~10-29 한 번에(원 단위, 정의 동일). 2,400콜·콜당 ~5초 ≈ 3시간, 차단 해제(10-31) 후 콜 간격 넉넉히. 재탐지 시 재차단.
3. 토스 `investor-trading` — **거래량(주)** 기준·등록외국인만이라 정의가 달라 부적합 (스펙 확인 2026-10-30).

## 주의
- VM(Cowork 샌드박스)은 호출마다 새 프로세스 → pykrx 가 매번 로그인 → 차단의 직접 원인. `krx_login()` 이 쿠키를 `/tmp/krx_session.json` 에 55분 재사용하도록 바꿨다. **맥에서 직접 돌리면 이 문제가 없다.**
- `foreign_ratio` 원본은 pykrx float16 잔재(48.28125 류). 새 행은 보유수량/상장주식수 정확값 — 차이 ≤0.01%p.
- 월말 스냅샷 종목 범위 = KOSPI+KOSDAQ 전체(우선주·스팩 포함, KONEX 제외). prices 는 원본 관례대로 기존 2,796 종목 + 2026-09 이후 신규상장 14종목만(원본이 빼놓은 ~230 소형주는 추가하지 않음 — 불연속 방지).
