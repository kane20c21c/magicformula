# 시장·섹터·종목 급락 대응 매뉴얼 — 스윙포트·데이포트 (2026-11-07)

> 출발: [[2026-11-06 쇼크일 갭 하락 vs 장중 하락 — 영향 지속성과 국면 게이트]] (코스피200 지수판) 을 장기 시계열(data_2015) 개별 종목·KRX 업종으로 확장.
> 목적(케인): **범위(시장·섹터·종목) × 크기 × 형태 (+ 거래량)** 에 따라 급락 뒤 주가가 어떻게 움직이는지 → 스윙포트·데이포트 대응 규칙.
> 이 문서는 **다른 세션의 연구와 합쳐 반영하기 위한 정본 요약**이다. 수치는 모두 이 세션(2026-11-06~07)의 재현 가능한 산출물에서 왔다 (§8).
> 표기: **[사실]** = 측정값 · **[클로이 의견]** = 해석 · **상태** = 채택 제안 / 그림자 후보 / 관찰 / 기각 / 철회. 판단은 케인.

### 1-4. 쇼크·크기
```
하루 수익 r_t = C_t / C_{t−1} − 1         (종가 기준)
쇼크: 종목 r ≤ −5% · 업종지수 r ≤ −3% · 코스피200 r ≤ −2%
크기 구간 (범위 간 '같은 드묾'으로 맞춤 — 종목 −5/−7/−10% 의 하위 3.42/1.35/0.44% 분위와 같은 수준)
  종목   작은 (−7%, −5%]   중간 (−10%, −7%]   큰 ≤ −10%
  섹터   작은 (−4.5%, −3%] 중간 (−6%, −4.5%]  큰 ≤ −6%
  지수   작은 (−3%, −2%]   중간 (−5%, −3%]    큰 ≤ −5%
```

### 1-5. 범위 — 종목 쇼크의 맥락
```
K_t = 코스피200 그날 수익
P_t = 같은 업종 다른 종목들(정상 행, 자기 제외, 5종목 이상)의 그날 수익 동일가중 평균
시장 동반 : K_t ≤ −2%
섹터 동반 : K_t > −2%  AND  P_t ≤ −3%
단독     : 그 밖 (P_t 계산 가능)
미상     : P_t 계산 불가
업종 매핑 : 연도 Y = Y−1 연말 KRX 업종 구성 · 겹치면 구성종목이 가장 적은(세분) 업종
           제외 코드 2181~2184(코스닥 소속부)·2189(코스닥 글로벌)·1027·2024(제조 집계)
           미매핑(옛 코스닥 IT 지수 폐지로 2024 이전 ~9%)은 가장 가까운 뒤(없으면 앞) 스냅샷으로 소급 (케인 (나))
섹터 쇼크 자체의 맥락 : 시장 동반 = K_t ≤ −2% / 섹터 단독 = 그 밖
```

### 1-6. 형태 — 갭 몫
```
갭 g = O_t / C_{t−1} − 1      장중 i = C_t / O_t − 1      (1 + r) = (1 + g)(1 + i)
갭 몫 φ = ln(1 + g) / ln(1 + r)
① 갭상승→붕괴 φ < 0     ② 장중 주도 0 ≤ φ ≤ 0.4     ③ 섞임 0.4 < φ < 0.6
④ 갭+추가하락 0.6 ≤ φ ≤ 1     ⑤ 갭→반등(장중 상승 마감) φ > 1
```

### 1-7. 거래량
```
v_t = V_t / 평균(V_{t−20} … V_{t−1})   (정상 행만, 최소 15일)
종목 저 v < 1.0 · 중 1.0 ≤ v < 2.0 · 고 v ≥ 2.0     (학습 3분위 1.06 / 1.82)
섹터 저 < 0.8 · 중 0.8~1.2 · 고 ≥ 1.2 (업종지수는 쇼크일에도 거래량이 거의 안 늘어 구분력 약함)
지수 저 < 1.0 · 중 1.0~1.25 · 고 ≥ 1.25 (코스피200 거래량은 2015~ 만)
```

### 1-8. 결과 지표
```
r10 / r20  : 쇼크 다음 날부터 10 / 20거래일 안에 종가 ≥ 쇼크 전날 종가(C_{t−1}) 인 날이 있으면 1  — '급락 전 주가 회복'
hold10     : 이후 10거래일 종가 모두 ≥ 쇼크일 장중 저가 L_t 이면 1   ⚠ 쿠션 편향(§3)
dd10       : min(C_{t+1..t+10}) / C_t − 1  — 10일 최대 추가 하락 (쇼크일 종가 기준, 중앙값)
a20        : C_{t+20} / O_{t+1} − 1 − 0.23%  — 다음 날 시가 진입 20일 수익 (왕복 비용 차감)
xb20       : f20 − β60 × (코스피200 같은 기간 수익),  β60 = 직전 60거래일 일수익 회귀 기울기
쿠션        : C_t / L_t − 1  — 쇼크일 종가가 저가 위에서 끝난 폭
```

### 1-9. 2차 하락
```
D2  = 쇼크 다음 날부터 10거래일 안에 C_d < L_t (쇼크일 저가) 인 첫날
D2' = 10거래일 안에 다시 r ≤ −5% 인 첫날 (확인용)
측정 = D2 다음 날 시가 진입 → +5·+10·+20일 수익(비용 차감), 20일 안 쇼크 전날 종가 회복, D2 저가 10일 유지, D2 종가 → 10일 최저 종가
```

② 시기 3개 부호 일치 — 종목·섹터 2015–19 / 2020–22 / 2023–26.5 · 지수 2000–07 / 2008–14 / 2015–26.5
