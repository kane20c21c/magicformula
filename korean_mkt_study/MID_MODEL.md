# 중기 모델 연구 — 결론 (MID_MODEL.md)

**상태 (2026-09-20)**: 연구 종결. "5~20일 보유 · 매일 순위 재평가" 상시 전략은 **기각**. 살아남은 것은 **급락 모듈(R2) v0.1 — 대기 상태**(국면 모니터 미배포, 가상계좌 없음).
**한 줄**: 12년 A층에서 평상시 5~20일 방향 정보는 없고, 기대값은 "시장 MA200 아래 + 급락 후 20거래일" 국면에만 생기며, 그 안에서도 종목 순위 정보는 없다(변동성 꼬리만 피하고 분산).

## 1. 질문과 정의

- 케인 정의(2026-09-16): 보유 5~20거래일, 경로 조건 타깃(손절·목표 도달), 매일 순위 재평가·교체(롤링).
- **라벨 = 트리플 배리어**: 진입 t+1 시가. 폭 = k·vol20·√N (vol20 = 20일 일간수익률 표준편차), k∈{0.5,1.0}, N∈{5,10,20}. 고가 ≥ 상단 → +1, 저가 ≤ 하단 → −1(같은 날 동시면 −1), 둘 다 아니면 만기 0. r_path = ±폭 / 만기수익률(배리어 체결·슬리피지 0), r_raw = N일 종가수익률. **주 판정 N=10, k=1.0.**
  - 부산물: 폭이 vol20 비례라 변동성 확장 종목은 양쪽 다 덜 닿음 → y_up/y_dn 단독·volexp 축은 방향 판단에 쓰지 않음(방향은 lab=−1/0/+1).
- 유니버스 3계층(월말 meta → 다음 달 적용): all(우선주·스팩 제외, 관리 아닌 달, 종가≥1,000, 20일 평균 거래대금≥10억) / big(시총≥4조) / bigf(big & 외인≥30%). all 셀의 92%가 small.
- 데이터(A층): `korean_mkt_study/data_ext/` 2014-01~**2026-09-11**(전 유니버스, `backfill_prices_krx.py` pykrx 수정주가·KRX 단독 거래량, 이음새 비율 스케일). 수급(investor_flow) 2026-06-30 종료(KRX 차단). **생존편향**(2026-06 상장 명단). 섹터 없음(meta.sector 전부 '기타'). 평가 2015-01-02~. 반분 A(<2021) / B(≥2021).
- 시장 지수 = all 유니버스 시총가중 일별 지수(KOSPI200 대용; 국면 띠가 KOSPI200과 거의 일치, `out/mid/market_ma.png`). 실운용 국면 판정은 LLV TIGER200(102110, 2023-01~).

## 3. 상황 사다리 (`mid_states.py`·`mid_states2.py`, `out/mid/ladder*_summary.md`, `states2.parquet`) — 어디서 기대값이 생기나

방법: 피처를 상태로 이산화 → 빈도순 사다리 → 셀 최소 3,000건·100일 → **전반(A)에서 찾고 후반(B)으로 확인** → 흔한 조건부터 하나씩 더하는 드릴다운. 원하는 상태 = p_up≥45% · p_dn≤20% · r_path≥+1%.

살아남은 국면 (N=10, k=1 · r_path 전체 / A / B):
- **시장 급락(20일 −8% 이하) 후 경과일**: 당일 +2.3% → 1~5일 +0.9% → 6~20일 +1.5%(p_dn 13.9%) → 21~60일 −0.8% → 60+ −0.2%. 다섯 구간 전부 A·B 일치. **창 = 당일~20거래일.**
- 급락 당일 × 시장200 아래+상승: p_up 46.4% / p_dn 8.8% / +4.8% (A +3.5 / B +5.1, 25일) — 2축으로 원하는 상태 도달 유일 셀. 급락 당일 × 시장200 **위**+상승(고공 조정, 2026-07~08): −0.7%.
- 회복초입(시장200 아래+상승) × 종목 아래: +0.4~+1.4%, 종목 MA 기간 무관, A·B 일치. 종목 위(역행 강세)는 −0.5~−1.3%.
- 시장 MA200 기울기 전환 며칠째: 1~5일 **−1.4%(p_dn 36%)** → 6~20일 +0.7% → 21+ 0. 전환 첫 주는 거짓 전환.
- 드릴(spread): gap5<−5 → 시장200 아래+상승 → 종목200 아래+상승 → dd20<−20: p_up 50.7% / p_dn 10.7% / +6.0% (A +4.6 / B +7.2), 6,673셀·273일 (→ R1, 시뮬에서 탈락 §4).
- 시장 이중 국면 200×60: 200 위+상승 × 60 아래+상승 +0.7%(7.7%, 일치); **200 위+상승 × 60 아래+하락 −2.1%(p_up 21.6%, 일치) = 2026-08-10~ 국면**.

죽은 것: 강세장(시장200 위+상승) 모든 종목 상태 ≈ 0 또는 음수; 고공 조정 안 모든 종목60 상태; 수급 4조합·상승/하락 거래량비·거래량 급증·정배열; **bigf 계층 전체**(드릴 2단에서 +0.4%로 정지 — 국면 효과는 중소형주 현상).

MA 기간 결론: 시장 축 = 200(대국면) + 60(중간 국면), 종목 축 = 60 기본. "아래+상승"은 P=120에서 조정 초입, P=200에서 회복 초입으로 갈리므로 순서 축(전환 며칠째)과 함께 써야 한다.

## 4. 시뮬 (`mid_sim.py`·`mid_sim2.py`·`mid_sim3_select.py`, `out/mid/sim*_summary.md`) — 셀 평균이 왜 포트 수익이 안 되나

10슬롯 동일비중 · t+1 시가 진입 · 배리어/만기 청산 · 왕복 0.30% · 일별 MTM.
- **슬롯 선택이 규칙보다 결과를 좌우**: R2 같은 규칙에서 gap5최저(깊게 빠진 순) CAGR +6.0%/MDD −44.6%, 거래대금최대 −2.3%/−59.1%, vol20최저 +4.8%/−25.9%, 무작위 +7.6%/−24.3%. "깊게 빠진 순"은 변동성 꼬리(배리어 폭 ±37%)만 뽑는다. 무작위가 이김 = 후보 안에 순위 정보 없음.
- R1(회복초입 스프링) 셀 평균 +6% → 시뮬 +2~3%: 후보 25/일 중 어떤 10개도 셀 평균에 못 미침(평균이 고변동 소수 표본에 끌림). R3(강세장 눌림) A +9.6% / B −3.3% 불일치. **둘 다 탈락.**
- R2 격자(창×슬롯×변동성상한×선택×손절슬리피지 72조합, `sim2_grid.csv`): 창 당일~20 최선(Sharpe 0.64 vs 당일~5 0.42, 6~20 0.53) · 슬롯 20~30 > 10 · vol 상위 25% 제외 +0.06 · 무작위 CAGR 5.5% > vol20최저 2.9% · 손절 슬리피지 1% = CAGR −1.1%p, Sharpe −0.16.
- **시드 분산**(`sim3_select.csv`, 30슬롯·slip 1%·vol 상위25%·거래대금 하위25% 제외): 무작위 3시드 CAGR +4.5 / +7.6 / +9.6%. 종목코드순 +5.7%/MDD −32.7%/Sharpe 0.57. 거래대금 작은 순 +9.1% > 큰 순 +2.5%(소형주 기울기 = 슬리피지 최악 구간).
- 대조: 유니버스 지수 CAGR +12.1% / MDD −44.0%. 모듈은 노출 15%로 절대수익은 못 미치고, 강세장 3년(2017·2025·2026)에 현금. 약세장 방어(2022 +10% vs 지수 −26%, 2018 −2% vs −16%)가 가치의 전부.
- 시뮬이 가정하는 것(실전에서 나빠질 요인): 배리어 가격 정확 체결(하한가 갭 관통 미반영), 시가 단일가 체결, 생존편향, 급락일 소형주 유동성.

## 5. 급락 모듈 R2 v0.1 — 사전 등록

```
시장 지수 = 유니버스 시총가중(연구) / TIGER200 102110(실운용)
무장(armed) 조건 : 지수 < MA200  AND  20일 수익률 ≤ −8% 가 찍힌 뒤 20거래일 이내
종목 조건       : 20일 고점 대비 낙폭 ≤ −12%  AND  all 유니버스(거래대금 20일 평균 ≥ 10억 등)
후보 필터       : 그날 후보 중 vol20 상위 25% 제외, 거래대금 하위 25% 제외
선택           : 종목코드순 (중립·결정론) — 슬롯 빈 만큼, 보유 중 종목 제외
슬롯·비중       : 30슬롯 동일비중 (진입 시 NAV/30)
청산           : 트리플 배리어 k=1.0, N=10 (진입가 × (1 ± vol20·√10)), 만기 종가
비용 가정       : 왕복 0.30% + 손절 슬리피지 1%
```
정직한 기대치(12년 시뮬): **CAGR +5~6% · MDD −30~−33%(2020-03 2차 급락) · Sharpe 0.5~0.6 · 승률 56% · 노출 15% · 거래 연 150~190건**. 후반(2021~) MDD −12%.

사전 판정 기준(실전/그림자 전환 시): 급락 국면 **3회 누적** 후 ① 노출당 연환산 ≥ +20% ② 국면당 MDD ≤ −20% ③ 배리어 체결 슬리피지 실측 ≤ 1.5% ④ 데이포트·화이트포트와 국면 상관. 하나라도 어긋나면 폐기, 규칙 수정은 새 시뮬로만.
