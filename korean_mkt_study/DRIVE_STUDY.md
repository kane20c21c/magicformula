# 드라이브 연구 — 정의·유형·경계·결과 (2026-11-02~03)

정본 코드: `korean_mkt_study/drive_types.py` (정의·고정 경계·point-in-time 빌더).
데이터: `data_2015/prices.parquet` (2015-01-02~2026-10-29), 유니버스 = 전년 평균 거래대금 ≥10억 **AND** 전년말 시총 ≥1,000억, 2016~.
산출: `out/crash/drive_pit_down.parquet`, `drive_pit_up.parquet` (k=3·4·5일차 시점 행).
급락·반등 룰 쪽 결과는 `bounce_rule/README.md` 참조. 이 문서는 "드라이브" 자체의 성질.

## 1. 용어 (케인과 확정)

| 용어 | 정의 |
|---|---|
| 드라이브 | sign(r_t) 가 같은 날이 **연속 n ≥ 3일**. r_t = C_t/C_{t−1} − 1, 종가 기준. r_t = 0 은 양쪽 모두 끊음. D1..Dn, D+1 = 종료 확인일 |
| 상승형 / 하락형 | r_t > 0 연속 / r_t < 0 연속 |
| 속도 A | \|r_Dn\| / \|r_D1\| — **가속형**(A 큼) / **감쇄형**(A 작음) |
| 거래량 T | V_Dn / V_D1 — **증가형** / **감소형** |
| 겹침 ō | mean_{t=D2..Dn} o_t, o_t = max(0, min(H_t,H_{t−1}) − max(L_t,L_{t−1})) / (H_t − L_t) — **계단형**(ō 작음, 갭) / **미끄럼형**(ō 큼) |

보조: v_level = 드라이브 평균 거래량 / 직전 20일 평균, v_last = 마지막날 거래량 / 직전 20일 평균.
버린 후보: 몸통(시가~종가) 겹침 — 37%가 정확히 0이라 분별력 없음. 갭 비중 Σ(O−C_{−1})/Σ(C−C_{−1}) — 범위 겹침과 같은 정보, 더 시끄러움.

## 2. 고정 경계 (2016~2026 point-in-time 3분위를 반올림)

| 축 | 하락형 | 상승형 | 비고 |
|---|---|---|---|
| 속도 A | 감쇄 < 0.65 / 가속 > 1.8 | 공용 | 3분위 실측 하락 0.639/1.833, 상승 0.524/1.869 |
| 겹침 ō | 계단 < 0.40 / 미끄럼 > 0.57 | 공용 | 하락 0.414/0.571, 상승 0.421/0.579 |
| 거래량 T | 감소 < 0.75 / 증가 > 1.25 | **감소 < 1.00 / 증가 > 1.90** | 하락 0.767/1.277, 상승 0.970/1.878 — 상승 드라이브는 거래량이 따라붙는 게 기본값(T 중앙 1.26 vs 0.98) |

연도별 안정성: 고정 경계 적용 시 각 해의 하위/상위 비중이 26~44%(대부분 30~38%). 2022년 계단 44%(갭다운 약세장). 2023년 이후 하락형의 속도·거래량 경계가 같이 낮아짐(A 2/3: 2.0→1.6, T 2/3: 1.4→1.2) — 최근 3년은 덜 가속·거래량 덜 붙음.
드라이브 길이(k=3 vs ≥4)에 따른 경계 차이는 작음.

## 3. 하락형 결과 (281,638건)

### 3.1 언제 끝나나 — 못 맞춤
- 다음날 하락 지속 확률: k=3 49.4%, k=4 47.8%, k=5 47.8%. 길이·시총·시장·거래량 수준·단일 유형 모두 ±2pt.
- 세 유형 27칸 교차: k=3 에서 45~53%. 마지막날 거래량 5배↑(클라이맥스)도 종료 49.5%.
- 깊은 하락(≤−12%, 38,195건)에서만 구조가 생김: **계단+가속** → 종료 60~64%, **계단+감쇄** → 종료 37~48%(= 이어질 확률 52~63%, "갭다운이 계속 나오는데 봉이 작아지면 아직 안 끝남"). 미끄럼은 속도 무관 50~53%.
- 결론: 종료는 D+1 종가로 **확인**하는 것. 예측 단계를 룰 앞에 둘 근거 없음.

### 3.2 끝난 뒤 저점을 지키나 (hold10 = D+2..D+10 종가 ≥ 드라이브 끝 종가, 기준 34.1%)
- 1순위는 D+1 반등 크기 (0~1% → 21%, 8%+ → 72~77%). 시총·길이 무관. [반등 룰 근거]
- 유형은 **깊은 낙폭에서만** 작동. 낙폭 ≤−12% & D+1 ≥3% (약 9,700건):

| 단독 | 하 | 상 | 폭 |
|---|---:|---:|---:|
| 거래량 T (감소→증가) | 46.5% | 65.1% | +19pt |
| 속도 A (감쇄→가속) | 47.4% | 64.8% | +17pt |
| 겹침 ō (미끄럼→계단) | 49.1% | 62.7% | +14pt |

| 겹침 × 거래량 | 감소 | 평탄 | 증가 |
|---|---:|---:|---:|
| 계단 | 53.8 | 60.0 | **68.5** |
| 중 | 46.4 | 52.6 | 64.1 |
| 미끄럼 | **43.3** | 52.1 | 58.5 |

- 세 변수는 한 묶음이면서(상관 겹침~속도 −0.25, 거래량~속도 0.39, 겹침~거래량 −0.32) 각각 독립 기여. 양 끝(계단-가속-증가 vs 미끄럼-감쇄-감소) 25pt 차이.
- 연도별(D+1≥3%, 계단−미끄럼 hold10 차): 11년 중 9년 양(+1.5~+14pt), 2020·2025 음(−11, −5) — 쇼크 뒤 V자 반등 해에는 구분 무의미.
- 주의: D→D+10 **수익률**은 hold10 만큼 깔끔히 안 따라옴("저점을 지키나"와 "얼마나 오르나"는 다른 문제).

### 3.3 두 가지 하락 유형 (해석)
| | 봉 구조 | 속도 | 거래량 | 반등 뒤 |
|---|---|---|---|---|
| A. 클라이맥스형 | 계단(갭다운) | 가속 — 마지막날 최대 | 증가 — 마지막날 최대(48%가 최대일) | 저점 유지 |
| B. 충격 후 흘러내림형 | 미끄럼(겹침) | 감쇄 — 첫날 최대 | 감소 — 첫날 2배↑ 터지고 마름 | 반등해도 다시 깸 |

계단식은 날별 중앙값 −1.65 → −2.41 → −2.55%, 미끄럼식은 −1.32 → −0.92 → −0.98%. 거래량 중앙(직전20일=1): 계단 0.74→0.82→0.99, 미끄럼 1.12→0.93→0.69. D+1 거래량은 둘이 같음(0.70~0.75).

## 4. 상승형 결과 (208,493건)
- 다음날 상승 지속: k=3 44.4%, k=4 43.7%, k=5 43.9%. 시총·시장·거래량·유형 모두 ±2pt (룩어헤드 주의: 드라이브 단위 파일의 "평균 거래량"으로 자르면 37→50%로 보이지만 뒤쪽 날 정보가 섞인 것).
- 3일차 → D3+10 수익: 3일차 +0.23%, 4일차 +0.31%, 5일차 +0.57% — 어디서 출발하든 같음. 내일 이어지면 +3%, 꺾이면 −2% 의 44:56 동전이라 기대값 0.
- 끝난 뒤 고점 재돌파 61.4%(미돌파 38.6%), D→D+10 −1.9%.
- 유형 효과는 하락형의 1/3 수준. 상승폭 ≥12%(25,308건): 가속+증가(8,128건) 고점 미돌파 45.1%·r10 −3.8% vs 감쇄+감소 37.6%·−2.2%. **겹침은 상승형에서 무정보**(계단·미끄럼 모두 38.5~38.8%) — 겹침이 하락형에서 작동한 건 "갭다운 = 공포"라는 비대칭 때문으로 해석.

## 5. 시장의 기본 결
- 극값 재접촉: 저점 재이탈 65%, 고점 재돌파 61%.
- 수익: 하락 드라이브 끝 → 10일 +2.5%, 상승 드라이브 끝 → 10일 −1.9%. 평균회귀 + 재시험이지 모멘텀 지속이 아님. 평균은 회귀하지만 **꼬리는 하락 쪽만 지속**(급락 연구 6.3% crash 기준).

## 6. 남은 것
- 하락형 유형(클라이맥스 점수)을 반등 룰의 2차 가중으로 쓸지 — 룰 영역(≤−20% & 1.65σ, 패널 역산 323건)에서 검증 필요. 쇼크 해(2020·2025)에선 무력.
- "계단+감쇄 = 아직 안 끝남"을 반등 룰의 보조 경고로 쓸지.
- 상승형 "고점 경고"(가속+증가로 끝난 큰 상승)를 배치에 얹을지 — 효과 7.5pt라 보류.

## 7. 상승 드라이브 — 길이와 3일차 초상화 (2026-11-03~04, 탐색)

케인 질문 두 가지: ① 드라이브 길이를 설명하는 변수가 있나(시총·변동성 등), ② 3일차에 서 있는 12.7만 건은 어떻게 생겼고,
내일 이어질 5.7만과 끝날 7만은 모습이 다른가. 설명 변수는 전부 **D0(첫날 전 거래일) 종가 시점**까지만 쓴다(케인: 당일 조건으로 넣지 말고 하루 어긋나게).
코드 `drive_length.py`·`drive_story.py`, 엑셀 `out/crash/drive_length_up_20261104.xlsx`·`drive_story_k3_20261104.xlsx`.

### 7.1 길이 (드라이브 단위 127,078건)
- 분포 3일 55.6% / 4일 25.0% / 5일 10.9% / 6일 4.8% / 7일 2.0% / 8일↑ 1.7% — 매일 44% 로 이어지는 **기하분포**. 첫날·마지막날 r 중앙 1.5~1.6% 로 길이와 무관.
- 3변수: 속도 A 는 길이와 무관(가속 34~36%·감쇄 38~40% 전 구간), 거래량 T 는 길이에 비례(1.27→2.02, 날이 쌓이면 따라붙는 동반 현상), 겹침 중앙 0.50~0.51 동일.
- D0 변수 17개 → 길이: Spearman |ρ| ≤ 0.064. **시총·변동성(σ20/σ60)·외국인 지분율·거래대금·시장·연도 전부 무정보**(5분위 P(n≥5) 19~20%).
  유일한 결 = 시장 상태: KOSPI 20일 수익 최하위 10분위 24.0% vs 최상위 17.4%, KOSPI 60일 낙폭 ≤−15% 에서 25.6%(3→4 지속 52%).
  그런데 쇼크 반등 해(2018 44%·2020 32%·2024 53%)에만 살고 2022(19.5%)·2026-10(21.0%)처럼 흘러내리는 약세장에선 효과 없음 → "낙폭"이 아니라 "급락 직후 V자".
- 회귀(12변수 로짓·OLS, 윈저화·표준화): McFadden R² 0.003~0.004, OLS R² 0.006. 다변량에서 거래대금(−)·시총(+)이 서로 통제되면 반대 부호 — 회전율 낮은 종목이 1pt 정도 더 감. 실무 크기 아님.
- 섹터는 `data_2015/meta.parquet` 의 sector 가 전부 '기타' 라 못 봄(재구성 때 미채움). 2026-10 말 진행 중 드라이브는 데이터 끝에서 잘려 길이 과소.

### 7.2 3일차 초상화 (k=3 시점 127,223건, 지속 44.4%)
- 전형: 3일 +5.8%(p25 3.5 / p75 9.4), 매일 같은 보폭. **갭이 아니라 장중**에 오른다(시가 갭 중앙 +0.2~0.3%, 장중 +1.3%, 갭 비중 중앙 18%).
  양봉 81~84%, 고가 갱신 82~84%, 저가 상승 88%, 종가는 봉의 70% 지점, 윗꼬리 26%. D3 봉 길이·거래량 중앙 ≈ 직전 20일 평균(0.95·0.97배) — **대부분 조용하다.**
- 출발: 46.5% 가 MA5·10·20·60 전부 아래에서 시작(되돌림형), 전부 위에서 9.6%. D3 엔 99% MA5 위, 72% MA20 위, 49.6% 4개 모두 위.
- 지속을 가르는 것(전부 40~50% 범위): D0 MA 전부 아래 46.3 vs 전부 위 42.0 · D3 MA 2개 이하 46~48 vs 4개 42.8 · 계단 46 vs 미끄럼 42(계단+감쇄+감소 50.2)
  · D3 종가 하단·긴 윗꼬리 46.4 vs 최상단 42.4 · 봉 작음·거래량 평소 45~46 vs 큰 봉·큰 거래량 42.8~43.5.
  "조용함 점수" 0→5: 41.2 → 50.6% 단조. 시끄러운 쪽이 상승폭은 크지만(+12.9 vs +5.3%) D+10 은 반대(−2.0 vs 0.0%).
- 조합을 더 얹어도 포화: 계단+감쇄+감소 + 봉 작음 + 거래량 평소 = 51.6%(n=1,003, 16~22 50.5 / 23~26 54.0). 유형이 이미 조용함을 담고 있어 봉·거래량이 추가 정보를 안 줌.
- 나무(16~22 학습 → 23~26 검증)에서 **하나만** 살아남음: **D3 종가 ≤ MA60 −10% AND D1 장중 > 4.5%** → 60.9%(n=3,288, 2.6%), 검증 62.4%, D+10 평균 +3.5%.
  임계 양방향 단조(MA60 −5→−20%, 장중 2→8%: 52→70%). 연도 2018 80·2020 73·2024 72 / 2021 47·2022 46. "낮은 자리 + 강한 첫날" = 반등 룰(룰 #5)의 거울상 — 같은 사건을 3일차에서 다시 보는 것일 가능성(겹침 비율 미확인).

### 7.3 두 집단은 같은 얼굴
- 이어짐(56,470) vs 끝남(70,753): 24개 연속 변수 **AUC 0.476~0.515, KS ≤ 0.04**. 최대 차이 = D3 종가/MA60 중앙 +1.1 vs +2.0%. 플래그 차이 ±3.6pt(D3 MA60 위 54.0 vs 57.4, D0 MA 전부 아래 48.6 vs 45.0).
  모든 변수 로지스틱 검증 AUC **0.523** — 예측 상위 10% 의 실제 지속률 49.3%.
- 6일↑(10,782) vs 3일끝(70,469)으로 극단을 비교해도 AUC 0.463~0.537, 로지스틱 0.53. 다른 결은 같은 하나 — "아직 낮다"(MA60 아래 52 vs 57%, D0 전부 아래 50 vs 45%, 계단 34 vs 31%). 거래량·속도·봉·갭은 긴 드라이브와 짧은 드라이브가 구분 불가.

### 7.4 결론
- 상승 드라이브의 길이는 종목 속성(시총·변동성·수급)으로 설명되지 않고, 드라이브 자체의 모양(거래량·속도·봉)으로도 "더 갈지"를 읽을 수 없다. 하락형 §3.1 과 같은 결론.
- 읽을 수 있는 것은 **출발 위치** 하나 — 눌린 자리(MA60 아래·시작 전 MA 전부 아래)에서 시작한 드라이브가 조금 더 간다. 평균회귀의 결과이지 모멘텀이 아니다.
- 따라서 "팔았는데 다시 드라이브가 오는 것"을 피하려면 드라이브 모양이 아니라 **종목의 위치(MA60·고점 대비)** 를 매도 기준에 두는 쪽이 데이터와 맞다.
- 남은 갈래: ① 7.2 의 60% 조합과 반등 룰 영역의 겹침 확인, ② 꺾인 뒤(D4 하락) 어떤 모양이면 다시 위로 드라이브가 생기나(재개).
